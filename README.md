# Планер

Адаптивное PWA-приложение для Android: задачи, расходы, календарь и лимиты бюджета. Данные сохраняются локально в браузере устройства.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Тесты финансовой логики: `npm test`.

## Установка на Android

Готовый APK находится в [релизах GitHub](https://github.com/UroborosTale/taastfin/releases). Поддерживается Android 6.0 и новее.

1. Скачайте `Planer.apk` на телефон и откройте файл.
2. Разрешите установку из выбранного источника, если Android запросит это.
3. После установки один раз откройте «Планер» для синхронизации виджетов.

### Виджеты домашнего экрана

- **Бюджет на сегодня** — остаток, потраченная сумма и прогресс дневного лимита.
- **Задачи на сегодня** — невыполненные дела, отсортированные по времени.

Для добавления удерживайте палец на свободном месте домашнего экрана → **Виджеты** → **Планер** → перетащите нужный виджет. Виджеты можно масштабировать; нажатие открывает приложение. Они обновляются после изменения расходов, задач и лимитов, а также периодически средствами Android.

### Сборка из исходников

```bash
npm install
npm run android:sync
cd android
./gradlew assembleDebug
```

APK будет создан в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Браузерная PWA-версия

Опубликуйте содержимое `dist` на HTTPS-хостинге и выберите **Установить приложение** в Chrome. PWA поддерживает standalone-режим и офлайн-запуск, но системные Android-виджеты доступны только в APK.

## Возможности

- Добавление и удаление расходов с категорией и датой, поиск по истории.
- Автоматический пересчёт баланса, недельного графика и дневного/недельного/месячного лимита.
- Редактирование лимитов с индикацией превышения.
- Создание, выполнение и удаление задач.
- Календарь с навигацией по месяцам, отметками задач/трат и добавлением дела на выбранный день.
- Адаптивная раскладка для телефона, планшета и компьютера.
